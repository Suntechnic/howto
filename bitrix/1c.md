## Авторизация
/bitrix/admin/1c_exchange.php?type=catalog&mode=checkauth

## Импорт
/bitrix/admin/1c_exchange.php?type=catalog&mode=init&sessid={sessId}

Загрузка файла:
/bitrix/admin/1c_exchange.php?type=catalog&mode=import&filename={ИмяФайла}

Если возникает ошибка проверки источника запроса:
```php
echo \Bitrix\Main\Config\Option::get("catalog", "DEFAULT_SKIP_SOURCE_CHECK");
\Bitrix\Main\Config\Option::set("catalog", "DEFAULT_SKIP_SOURCE_CHECK", "Y");
echo \Bitrix\Main\Config\Option::get("sale", "secure_1c_exchange");
\Bitrix\Main\Config\Option::set("sale", "secure_1c_exchange", "N");
```

Чтобы отключить архивы, нужно здесь /bitrix/admin/1c_admin.php?lang=ru
Снять галку *Использовать сжатие zip, если доступно*
Там же отключить контроль по хэш-суммам.

Метка импорта заказа в таблице b_option зависит от файла и начинается с last_export_time_committed_%

### Константа резервирования файлов на диске:
```php
define("BX_CATALOG_IMPORT_1C_PRESERVE", true);
```

## Экспорт заказов
/bitrix/admin/1c_exchange.php?type=sale&mode=init&version=2.10&sessid={sessId}
Сначала выполнить запрос /bitrix/admin/1c_exchange.php?type=sale&mode=query&version=2.10 для того чтобы получить идентификатор сессии.

Сброс флага обмена заказа:

```php
use Bitrix\Sale\Order;

$orderId = 205921;
$order = Order::load($orderId);

if ($order) {
    // 1. Сбрасываем флаги обмена с 1С
    $order->setField('UPDATED_1C', 'N');
    $order->setField('EXTERNAL_ORDER', 'N'); // На случай, если он помечен как созданный в 1С
    
    // 2. Принудительно обновляем дату модификации на текущую
    $order->setField('DATE_UPDATE', new \Bitrix\Main\Type\DateTime());
    
    // 3. Сохраняем с отключением провайдеров (чтобы не пересчитывать скидки и доставку)
    $order->save();
    
    // 4. Очищаем кэш модуля sale, чтобы компонент обмена увидел изменения
    \Bitrix\Main\Data\Cache::clearCache(true, '/sale/export/');
    
    echo "Заказ №{$orderId} успешно обновлен и подготовлен.";
} else {
    echo "Заказ не найден.";
}
```
